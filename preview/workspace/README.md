# Personal Workspace Preview

Interactive **layout-only** preview for XiaoColour’s left-sidebar + right-workspace redesign.

- Does **not** modify the live site, auth, D1, or Global Pulse.
- Mock data only; changes are not persisted.

## Run locally

From the repo root:

```bash
npx --yes serve . -l 43128
```

Open [http://127.0.0.1:43128/preview/workspace/](http://127.0.0.1:43128/preview/workspace/).

1. Click **进入 Personal Workspace**
2. Switch Overview / Little Notes / My Days / Footprints in the left nav
3. Narrow the viewport to try the mobile drawer
